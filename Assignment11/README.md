## Overview
This project explores how educational attainment deviates from structurally
expected levels across a wide sample of countries. Drawing on Amartya Sen's
capability theory and Johan Galtung's notion of positive peace, it uses GDP
per capita and tax revenue per capita as proxies for structural capacity, and
Learning-Adjusted Years of Schooling (LAYS) as the educational outcome.

## Data
- `educational_gaps.csv` — personally constructed from the Positive Peace Report (2024)
- `API_GC.TAX.TOTL.GD.ZS_DS2_en_csv_v2_1167.csv` — World Bank tax revenue data (2019)
- `API_NY.GDP.PCAP.CD_DS2_en_csv_v2_245.csv` — World Bank GDP per capita data (2019)

## Files
| File | Description |
|------|-------------|
| `Assignment11_Script.R` | Loads data, builds regression models, saves all tables and figures |
| `main.tex` | LaTeX document that embeds R outputs automatically |
| `tab/` | Regression tables (.tex) generated by modelsummary() |
| `img/` | Figures (.pdf) generated by ggplot2 and ggsave() |
| Ignore all other files and folders. They are for personal use in the paper’s submission to PE Class|

## How to reproduce
1. Open the project from the `assignment11/` folder
2. Run `Assignment11_Script.R` — this populates `tab/` and `img/` automatically using relative paths
3. Upload the contents of `tab/` and `img/` to the corresponding folders in Overleaf
4. Compile `main.tex` — the table and figures are embedded automatically
